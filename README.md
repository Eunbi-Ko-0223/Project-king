# 오늘도 굽습니다 🔥

한국 신입사원의 회식 눈치 고충을 담은 삼겹살 굽기 웹 게임.

플레이어는 막내 신입이 되어 삼겹살을 굽고, 쌈을 싸서, 상사 네 명의 취향과 서열에 맞춰 대접한다. 누구에게 먼저 줄지(서열), 고기를 어떻게 구울지(굽기), 쌈을 어떻게 구성할지(재료)에 따라 점수가 오르내린다.

## 지금 상태

- **로직 프로토타입** 단계. 그래픽은 텍스트와 이모지로 대체했고, 재미가 검증되면 2.5D 실사 아트로 교체한다.
- `index.html` 하나로 돌아간다. 파일을 브라우저로 열면 바로 플레이된다.

## 파일

- `기획서.md` — 전체 게임 기획서 (컨셉, 상사 취향 매트릭스, 점수 시스템, 로드맵)
- `index.html` — 로직 프로토타입

## 핵심 아이디어

상사마다 좋아하는 "정답 쌈"이 숨어 있고, 플레이어가 만든 쌈이 그 정답에서 얼마나 떨어졌는지를 거리로 채점한다. 정답을 알려주지 않는 대신 상사가 표정과 한마디로 방향을 흘리고, 플레이어는 그 단서로 눈치껏 취향을 알아맞힌다.
